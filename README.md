# ShikshaSetu AI

> **Bridging the digital divide through AI-powered, inclusive education.**

ShikshaSetu AI is an AI-powered education platform designed to make quality learning more accessible to students from rural, underserved, and low-connectivity communities.

## Features

* **Personalized Learning** — Learning experiences tailored to individual students.
* **AI-Powered Educational Assistance** — AI support for learning, questions, and educational guidance.
* **Multilingual Support** — Educational assistance designed to support multiple languages.
* **Scholarship Discovery** — Helps students discover relevant scholarship opportunities.
* **Low-Bandwidth Support** — Designed for environments with limited internet connectivity.
* **Offline-Friendly Access** — Supports learning in situations where continuous internet access is unavailable.
* **Education Resources** — Provides educational resources for underserved communities.

## Tech Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* Django
* FastAPI

### Database

* PostgreSQL

### AI

* RAG
* LLM

## Project Vision

ShikshaSetu AI aims to make quality education more accessible to students from rural and underserved communities by combining artificial intelligence, personalized learning, multilingual assistance, scholarship discovery, and low-bandwidth accessibility.
